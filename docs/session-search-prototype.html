入口与作用域

入口收在项目右键菜单「搜索会话」（与行尾 ⋯ 同源），搜索框按需出现在会话块首行——不搜索时零常驻元素，与「会话行操作收进右键菜单」同一决策路线。行内第三颗常驻图标的备选方案未采用（挤占标题区）。收起项目即清空并收起，Esc 两次 = 清词 → 收框。

两段式体验

输入瞬间按标题/摘要过滤已加载列表（前端、零延迟、列表不空白）；300ms 防抖后异步全文搜索本项目全部 jsonl，结果原地合并。仅标题命中的行带「标题」小徽标区分。

命中行形态

复用 SessionRow：标题（关键词高亮）+ 片段行（约 60 字符截断）+ 右缘命中数。顺序保持 mtime 倒序不变——与正常列表同一心智模型，不按命中数重排。

已置顶会话参与搜索

正常列表里置顶会话被滤到顶部聚合区，但搜索时必须召回——否则它们在内容层面永远找不到。命中行图钉呈已置顶态（accent 色），提示它同时在置顶区（试「拖拽」）。

状态与空态

搜索中：spinner +「正在搜索会话内容…」（标题过滤已先行生效）；完成：「N 个会话 · M 处命中 · 0.6s」；无命中：块内一行空态。搜索失败就近贴状态行，不弹窗、不丢已过滤列表。

点击命中 → 跳转

打开右侧查看器并定位首个命中：自动加载所在分页、展开对应活动组——完全复用现有 jumpTo 跨分页跳转链路，零新增跳转机制。Esc / 清除按钮还原列表。

实现约束：图标全部沿用 Icons.tsx 既有 SVG（本方案零新增图标）；不新增按钮类——清除按钮复用 .search-clear 形态，无墨迹居中新债；命中高亮 <mark> 取 --accent-soft / --accent 主题变量，深浅两套自动适配。上限沿用单文件 MAX_SEARCH_HITS=200，跨会话最多展示 50 会话、每会话 1 条片段，超出折叠为「还有 N 个会话」一行。
